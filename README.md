# Seaborn Data Visualization Practice

This repository contains my practice work and assignments based on **Seaborn**, a Python data visualization library built on top of Matplotlib.

## Topics Covered

* Statistical data visualization
* Distribution plots
* Histograms
* Box plots
* Scatter plots
* Bar plots
* Count plots
* Pair plots
* Heatmaps
* Customizing plots with titles, labels, and grids

## Tools & Technologies

* Python
* Pandas
* Matplotlib
* Seaborn
* Jupyter Notebook

## Purpose

The purpose of this repository is to practice data visualization techniques using Seaborn and understand how different plots can be used to analyze and interpret datasets.

## Assignments

The notebooks include practical exercises such as:

* Creating distribution plots using `sns.histplot()`
* Creating box plots to identify data spread and outliers
* Creating scatter plots to analyze relationships between variables
* Creating pair plots for multiple numerical variables
* Creating correlation heatmaps
* Adding titles, labels, and other plot customizations
